Windows shows a warning

BBF Code is not code-signed yet, so SmartScreen says “Windows protected your PC”. Choose More info, then Run anyway.

macOS blocks the first launch

The app is not notarized yet. Right-click BBF Code in Applications and choose Open, or run xattr -dr com.apple.quarantine "/Applications/BBF Code.app".

Older Linux distributions

The .deb and .rpm need glibc 2.34 and OpenSSL 3. On anything older, use the .tar.gz, which carries no such requirement.

You need a company account

BBF Code asks you to sign in with your Blackbox Factories Google account before the editor opens. The AI Coder needs it too.
